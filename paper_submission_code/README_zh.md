# 皮肤与鼻腔微生物组的定殖模块研究

本仓库包含了关于皮肤和鼻腔微生物组定殖遗传基础研究的绘图与分析源代码。

## 项目概述

微生物定殖是其在宿主相关生态系统中长期持续存在的先决条件。本项目通过大规模比较基因组学框架，系统研究了暴露上皮生境（皮肤和鼻腔）中定殖决定因素的遗传组织结构。

### 核心发现
- **高质量资源库**：构建了包含 7,248 个代表性宏基因组组装基因组（MAGs）的参考数据集，覆盖鼻腔、皮肤及环境生境。
- **定殖因子 (CFs)**：通过基因型-生境关联（GHA）分析鉴定了 31 个 CFs，重点关注富集信号最强的（前 0.2%）宿主相关蛋白质家族。
- **定殖模块 (CMs)**：解析出 18 个 CMs，反映了在营养获取（如蛋氨酸摄取）、环境压力适应（如氧化应激耐受）和细胞维持方面的协同遗传系统。
- **组织原则**：证明了生态特化（而非系统发育亲缘关系）是上皮表面定殖系统多样化和部署的主要驱动因素。

## 快速入门

### 环境依赖
运行绘图脚本需要 **R (>= 4.0.0)** 以及以下软件包：
- `tidyverse`, `ggplot2`, `patchwork`, `scales`, `vroom`, `RColorBrewer`, `ComplexHeatmap`

### 使用方法
每个图表目录下都包含生成对应面板的具体 R 脚本。例如，要生成 Figure 1：
```R
source("scripts/plotting/Figure1/Figure1C_Taxonomic_Diversity.R")
```
*注意：请确保将工作目录设置为本仓库的根目录。大多数脚本依赖于 `scripts/utils/配色.R` 以保持视觉风格的一致性。*

## 数据获取
本研究使用的基因组数据包括来自 4D-SZ 队列、UHSG、HSMG 以及 GEM 目录的 MAGs。处理后的系统发育图谱和 MI Z-score 存放在 `data/` 目录中（或通过手稿中提供的链接获取）。
